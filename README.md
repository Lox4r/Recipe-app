
# Recipe App

A web application that allows users to discover,
create, organize, and manage their favorite recipes.

## Technologies
- Next.js 16
- TypeScript
- Tailwind CSS
- MongoDB (planned)
- Authentication (planned)

## Planned Features
- User registration and login
- Browse and search recipes
- Create new recipes
- Edit and delete personal recipes
- Save favorite recipes

## Getting Started

Install dependencies:

npm install

Start the development server:

npm run dev

Open http://localhost:3000
